## subject

Stage B §3 architecture decision memo — the shape of the shared semantics (candidates A/B/C), the quantity/domain-type/obligation-language seam, cross-domain composite traces, equality relations, assumption attachment, and identifier governance

## findings

**The three shapes against the five tests.** Shape A (one universal IR) fails on a fork. Variant A1 — one maximally expressive calculus in which every domain object is representable — reproduces OpenMath: a tiny term kernel whose symbols reference dictionaries, where the hard semantics (branch cuts, partiality, units, regimes) live in prose and conformance is encoding-level. The Stage A digest's verdict is the controlling lesson: an IR without owned checkable semantics is a serialization format, and it survives only where a deployment channel forces it (none did; the CD repo has been dormant since 2022-06-28). Variant A2 — lower everything into one predicate/term calculus with owned semantics — is a direct fidelity-test failure: molecular graphs, tensors, genomic coordinates, and equations become generic predicates precisely "to preserve one IR," the amended Gate 1 rule's named prohibition. The apparent third way — a "universal" IR that natively contains typed graphs AND tensors AND coordinates AND equations — is shape B with the envelope boundary erased: every domain typing rule (e.g., "the unit of a rate constant is (mol/L)^(1−n)·s⁻¹, n from the rate law") accretes into one kernel, so the proof kernel is no longer small, any domain change bumps the universal version, and all standing receipts key on it. The local Nibli precedent cuts the same way: its single FOL LogicBuffer works *because* scope is deliberately FOL-only. SMT-LIB is the positive control: one sorted logic with fail-closed declarations succeeds for exactly one domain (entailment), and its own community's twenty-year failure to converge a universal proof format across mere theory-combinations is a measured ceiling on universalism even inside logic. Solo+12mo: A is a research programme, not a build.

Shape C (minimal claim/evidence core + fully independent per-domain obligation languages) fails the cross-domain tests. It forfeits the co-residence value that produced the chem+bio-first ruling: chemistry invariants (ChEBI-bound species identity, stoichiometric balance) function as compile-time checks on biology models only inside one compiler; under C they degrade to conventions, and Stage A measured what conventions cost (SBML's advisory units + optional annotations → ~50% of 455 published models irreproducible). The SageMath lesson is structural: cross-domain terms need canonical morphisms with typed failure, and morphisms need a shared type spine to be *from* and *to*; C has none, so every bridge is a pairwise, hand-maintained adapter — the N² phrasebook burden that died with OpenMath's grants and that Sage spent 700k lines partially taming. The composite traces below show C's specific fracture: correlation structure across domains cannot travel. Solo+12mo: four independent typed languages is four products.

**Recommendation: Shape B, with two refinements that prevent decay into A or C.** (1) *Two spines*: the envelope is the claim spine (claims, evidence, contexts, verdicts/dispositions, quantities, identifiers, equality); the mathematics IR is the computational lowering substrate — domain IRs form a typed import DAG (physics and chemistry import math; biology imports chemistry and math), and every *numeric* obligation payload is a math-IR expression with an explicit domain of definition, produced by a deterministic, citable lowering owned by the emitting domain IR. Sharing between domains happens either through envelope types (quantities, identifiers) or through declared DAG imports — never through string conventions. (2) *Envelope admission rule*: a type enters the envelope only if (i) ≥2 domain IRs need it, (ii) it has an external-standard oracle (the transcription-only ruling), and (iii) its values must cross a domain boundary uninterpreted. Quantities, uncertainty, correlation structure, identifiers, contexts, and time instants pass; tensors, molecular graphs, frames, and coordinates fail (they are interpreted by their owners) and stay domain-side.

**The seam.** Envelope: Quantity (payload = exact rational | float with §0.5 exactness class | interval | distribution ref; UCUM-grammar unit over SI 9th-ed base; quantity-kind identifier; optional GUM uncertainty ref), covariance/correlation objects, the claim-kind system, contexts/regimes/lifting, verdict/disposition, identifiers, equality relations. Domain IRs: math — expressions, functions-with-domain-of-definition, equations, first-class unevaluated forms, tensors as typed multilinear objects; physics — frames, quantity fields (math tensor + envelope quantities + frame label), physical model laws with regime predicates; chemistry — molecular graphs (IUPAC/InChI-anchored identity), species, reactions, rate laws, stoichiometry; biology — sequence/coordinate types (GA4GH VRS shape: sequence reference + interbase interval as components of the *type*), organisms/strains, assay context schemas. Obligation languages are a third species — neither envelope nor domain IR: a typed problem statement handed to a solver, on the SMT-LIB set-logic + SciMLBase-problem-type + SED-ML/KiSAO pattern. Each declares eight things: input signature (envelope + domain types), fragment (set-logic analog — constructs outside it are compile errors, the static ancestor of out_of_regime), method identity as a governed vocabulary term (KiSAO where it exists) with *typed* parameters (tolerances are Quantities, unit-checked), budget, result subset (which verdicts/dispositions it may return, with payload types), determinism class + seed requirements, backend binding constraints (solver identity + version), certificate kind offered. Proposed four-wide inventory (seven designed, three built in the vertical): obl:logic (entailment over assembled context; proved/disproved/unknown + certificate; emits SMT-LIB/TPTP), obl:exact-linear-algebra (declared ring/field; exact answers, level-1 exactness), obl:uncertainty-propagation (measurement model as math-IR function; GUM LPU vs JCGM-101 Monte Carlo as method terms; correlation object in, budget out), obl:ode-simulation (lowered reaction network/DAE; KiSAO algorithm term; tolerances; trajectories + receipt), obl:stochastic-simulation (SSA family; seed mandatory), obl:symbolic (rewrite/differentiate/integrate under theory scope; side conditions discharge or return unevaluated/conditional forms — typed partiality per amended Gate 1), obl:optimization (objective/constraints with units; termination criteria typed), plus obl:enclosure (interval/Taylor-model; results are proved-with-certificate per the Stage A ruling). The vertical needs logic, uncertainty-propagation, and ode/stochastic-simulation only.

**Traces.** T1, rate constant: k = 4.2×10³ L·mol⁻¹·s⁻¹, measured in an assay at 303.15 K. Envelope: Quantity + GUM budget + measurement claim (protocol, context record). Chemistry: k attaches to a typed Reaction; the rate law fixes k's unit as a *function of reaction order* — under B the chemistry IR emits that as an envelope unit equation the checker verifies without knowing what a rate law is; under A it is one more domain rule inside the universal kernel; under C the unit lives in chemistry's private quantity type, and when the same k enters a physics-side Arrhenius fit the bridge is documentation — a fidelity failure by the "conventions enforced only by documentation" clause. Biology supplies the assay context schema; physics supplies temperature as the regime variable for Arrhenius validity — under B one envelope quantity type serves both regime predicate and model input; under C it is two types plus a hand morphism. T2, the yeast vertical: glucose/O₂/CO₂ measurements at shared declared T,P — gas-law conversion (physics) and stoichiometric consistency (chemistry) at stated uncertainty. The shared T,P make the propagated uncertainties *correlated*; the covariance must span both domains' lowerings inside one propagation obligation. B: envelope carries quantities + one covariance object; physics and chemistry each lower to math-IR functions; one obl:uncertainty-propagation consumes the composite model. C: propagation runs per-domain and the correlation is silently lost or hand-carried — the strongest single argument for quantities+uncertainty in the envelope, and it feeds the pre-registered B.7 don't-build trigger. A: works mechanically but the gas-law function and species are generic predicates — fidelity fail. T3, variant→enzyme kinetics: "variant X (VRS-typed coordinates) reduces k_cat of enzyme E by 40%±5% at 310 K." The enzyme is a biology entity (gene product) *and* a chemistry species (catalyst) — a cross-namespace identity needing a declared, typed, transcription-backed morphism (UniProt↔enzyme/ChEBI cross-references), not a name pun; B's identifier layer carries typed cross-namespace links with fail-closed unresolved ends; C makes the link a convention; A trivializes identity but encodes coordinates as predicates. T4 (compressed), ΔG = ΔH − TΔS from imported CODATA/NIST table assertions constraining a flux model: symbolic manipulation (math) over imported-database claims (envelope kinds) at temperature (physics) in a biology model — exercises the same seams and adds nothing new; B handles it with the same three mechanisms.

**Equality.** Three named relations, never one overloaded `=`: (1) `=` exact/definitional, decidable per type, with the identity *layer* declared per type (for molecular graphs: which InChI layers count); (2) `approx_within(tol, metric)` where tol is a Quantity unit-checked against operands and metric is named (abs/rel/vector norm) — never a bare float, criterion cited in the basis (Nibli's disclosed isclose vs exact num_equal is the local precedent for naming both); (3) enclosure containment, proved-with-certificate. Plus one fail-closed rule: `=` between two measurement-kind claims is a compile error — comparing measurements is a statistical criterion returning supported/refuted/indeterminate{measurement, margin}. **Assumptions** attach at three typed points: theory scopes and assumption bundles at the *context* (Cyc microtheory ruling; lifting explicit and fail-closed), validity regimes at the *model* (typed predicates over context variables, per A.5.4), side conditions at the *operation* (discharge or typed-partial result). Obligations snapshot the context ref into the basis. **Identifiers**: CURIE-form prefix:local-id everywhere an external registry exists, resolved against a first-party committed prefix registry that pins per prefix: source registry, release version, license, and the mechanizable oracle (transcription-only compliance); Bioregistry-aligned prefixes where defined. Units are *not* CURIEs — compositional UCUM expressions cannot be enumerated. Claim/context ids are content-addressed digests (the VRS computed-identifier algorithm — truncated SHA-512, base64url — over a canonical serialization), which is what CQ-D2's invalidation walk keys on. Changing a pinned registry release is a new context version (supersession, A.5.3). Honest counterargument the architect must weigh: B's failure mode is envelope creep toward A; the admission rule is this memo's proposed control, and no shipped system has demonstrated such a rule holding over years — SBML's optional-package regime is the nearest precedent and it stalled rather than crept, which is the failure B's no-optional-packages discipline is designed against.

## design_recommendations

- **decision**: Overall shape of the shared semantics | **recommendation**: Adopt Shape B — one shared semantic envelope (claims, evidence, contexts, verdicts/dispositions, quantities, identifiers, equality) containing typed domain IRs — refined with the two-spine rule: the envelope is the claim spine; the mathematics IR is the computational lowering substrate; domain IRs form a typed import DAG (physics, chemistry import math; biology imports chemistry + math). | **rationale**: Only B passes all five tests: domain objects stay natively typed (fidelity), the four-wide design with chem+bio-first build is coherent (design four IRs against one stable envelope, implement two), the envelope owns checkable semantics end-to-end (OpenMath lesson), morphisms have a spine to attach to (SageMath lesson), and one envelope + two domain IRs + three obligation languages fits solo+12mo. | **alternatives_rejected**: A (universal IR): either OpenMath-style prose semantics or generic-predicate encodings — a named fidelity failure — or kernel accretion of every domain typing rule; twenty years of SMT proof-format fragmentation caps universalism even within logic. C (independent per-domain languages): forfeits the compile-time co-residence checks that motivated chem+bio pairing, loses cross-domain correlation structure (T2), and creates N² hand-maintained bridges — the phrasebook burden that killed OpenMath's ecosystem.
- **decision**: Where quantities-with-units live | **recommendation**: In the envelope, as one Quantity type: payload (exact rational | float with §0.5 exactness class | interval | distribution ref) + UCUM-grammar unit expression over SI 9th-edition base units + quantity-kind identifier + optional GUM uncertainty ref. Covariance/correlation structure is a first-class envelope object. Chemistry amounts, physics measurements, solver tolerances, and obligation parameters all use this one type. Missing unit = compile error, no exceptions. | **rationale**: The yeast trace (T2) is decisive: shared-T,P correlations must travel across physics and chemistry lowerings inside one propagation obligation, which requires one quantity/uncertainty layer above both. Modelica (unit defaults to "", tool-dependent checking) and SBML (units optional, 105xx warnings) measured the cost of fail-open units. | **alternatives_rejected**: Per-domain quantity types (Shape C) — correlation loss and hand bridges. Units as annotations checked by tools (Modelica/SBML precedent) — the documented fail-open path. Units as CURIEs — compositional unit expressions cannot be enumerated in a registry.
- **decision**: Where domain types live, and the envelope admission rule | **recommendation**: Molecular graphs and reactions in the chemistry IR; genomic coordinates (VRS shape: sequence reference + interbase interval as type components), organisms, assay schemas in the biology IR; tensors, functions-with-domain-of-definition, equations, unevaluated forms in the math IR; frames and quantity fields in the physics IR. A type may enter the envelope only if (i) ≥2 domain IRs need it, (ii) it has an external-standard oracle, and (iii) its values cross domain boundaries uninterpreted. Cross-domain type reuse otherwise goes through declared DAG imports. | **rationale**: Keeps the envelope small enough to own checkable semantics for everything in it, while the fidelity test is satisfied domain-side; the admission rule is the explicit control against B decaying into A by creep. | **alternatives_rejected**: Everything in the envelope (= Shape A by creep). Domain types shared by convention or string reference (SED-ML's XPath addressing is the documented brittleness precedent). Tensors/graphs as envelope types — they fail criterion (iii): they are interpreted by their owning domain, not passed through.
- **decision**: Obligation languages as a third species with a fixed declaration schema | **recommendation**: Define obligation languages as typed problem statements distinct from both envelope and domain IRs, in a closed inventory. Every obligation language declares: input signature (envelope + domain types), fragment (SMT-LIB set-logic analog, fail-closed), method term (KiSAO where applicable) + typed parameters (tolerances are Quantities), budget, result subset (permitted verdicts/dispositions + payloads), determinism class + seed requirements, backend binding constraints (solver identity + version), and certificate kind. | **rationale**: This is the convergent shape of every working precedent: SMT-LIB's set-logic + sorted declarations, SciMLBase's AbstractSciMLProblem types dispatched via solve(prob, alg), FMI 3.0.2's modelDescription typed variables + capability flags, CWL's fail-closed typed tool contracts, and SED-ML's KiSAO algorithm + parameter terms. Declaring the result subset per obligation makes 'a solver returned something it cannot mean' a type error. | **alternatives_rejected**: Obligations as raw domain-IR terms handed to adapters (semantic mismatches leak at the text seam — Sage's pexpect lesson). One universal obligation format (the SMT-COMP proof-track death shows even one community couldn't converge one); per-backend ad-hoc calls with no declared fragment (the silent-degradation path Stage A's backend_unavailable rule forbids).
- **decision**: v1 obligation-language inventory | **recommendation**: Design seven four-wide: obl:logic, obl:exact-linear-algebra, obl:uncertainty-propagation (GUM LPU | JCGM-101 MC as method terms), obl:ode-simulation, obl:stochastic-simulation (seed mandatory), obl:symbolic (side conditions discharge or return typed-partial/unevaluated results), obl:optimization; plus obl:enclosure (results proved-with-certificate per the Stage A ruling). Build three for the chem+bio vertical: logic, uncertainty-propagation, ode/stochastic-simulation. | **rationale**: Covers every solver class the four domain requirement sets and the §14 vertical invoke, maps 1:1 onto existing backend ecosystems (ATP/SMT, exact-LA, GUM tooling, CVODE/SSA via KiSAO terms, CAS, NLP solvers, interval libraries), and the built subset is exactly what CQ-D1/D2 and the yeast exhibition exercise. | **alternatives_rejected**: A single generic 'compute' obligation (loses per-class result-subset typing — non_convergent is meaningless for obl:logic, proved is meaningless for ode-simulation). Merging stochastic into ode-simulation (determinism class and seed obligations differ; KiSAO separates the families). Domain-keyed obligations like obl:chemistry (obligations are solver-class-shaped, not domain-shaped — one ODE obligation serves chemistry kinetics and physics dynamics alike).
- **decision**: Cross-domain term unification: canonical morphisms with typed failure | **recommendation**: All cross-domain lifting and identity bridging goes through a committed, versioned morphism registry: each entry names source type, target type, direction, losslessness, and its external transcription authority (e.g., UniProt cross-references for gene-product↔species identity). Missing morphism = compile error naming the pair; lossy conversion is always explicit; no heuristic pushout anywhere. | **rationale**: The SageMath lesson verbatim: canonical coercion is the one mechanism that made 90+ backends coexist, and its documented weakness — heuristic, best-effort pushout ('not all parent pairs yield a common structure') — is exactly what fail-closed compilation must replace with a typed error. Trace T3's enzyme (biology entity and chemistry species) is unrepresentable without a typed identity bridge. | **alternatives_rejected**: Heuristic pushout (Sage's own caveat). Name-based identity across namespaces (the pun that Nibli's obligated/obliged converse-alias incident shows survives review until it fails). Bridges as documentation conventions (the fidelity test's named failure mode).
- **decision**: Equality: three relations, never one overloaded = | **recommendation**: (1) `=` exact/definitional, decidable per type, with the identity layer declared per type (molecular graphs: which InChI layers participate); (2) `approx_within(tol, metric)` with tol a unit-checked Quantity and metric named (abs | rel | named vector norm); (3) enclosure containment, always proved-with-certificate. Additionally: `=` between two measurement-kind claims is a compile error — measurement comparison must go through a declared statistical criterion returning supported/refuted/indeterminate{measurement, margin}. | **rationale**: Collapsing these is how a float isclose silently becomes a truth claim; Nibli's own split (disclosed tolerant product/sum equality vs exact num_equal) is the working local precedent for naming both. The measurement-equality ban structurally enforces Stage A's uncertainty separation and the §14 limiting-reagent outcome. | **alternatives_rejected**: One polymorphic = with per-context semantics (the CAS-ecosystem ambiguity Sage wraps but never eliminates). Two relations only, folding enclosure into approx (loses the proved-with-certificate status the Stage A amendment assigns enclosures). Tolerance as an unnamed engine-wide default (undisclosed epsilon = a hidden model assumption, violating fail-closed).
- **decision**: Attachment of theory scopes and assumptions | **recommendation**: Three typed attachment points, no others: theory scopes and assumption bundles attach to contexts (imported as versioned named artifacts; lifting explicit, deterministic, fail-closed per the Cyc ruling); validity regimes attach to models (typed predicates over context variables, three-outcome checking per A.5.4); side conditions attach to operations (discharge against context, or return a first-class unevaluated/conditional form). Every obligation embeds its context snapshot reference in the result basis. | **rationale**: Each point has a distinct failure semantics already fixed by Stage A (failed lift = out_of_regime; missing regime variable = invalid_input; undischarged side condition = typed partiality), and pinning attachment points keeps assumptions out of prose — the amended fidelity test's requirement that no obligation is enforced only by documentation. | **alternatives_rejected**: Assumptions as global flags (Modelica's tool-dependent semantics precedent). Assumptions inline in expressions only (unliftable, unauditable across contexts). A single assumption bag per model (conflates regime, theory scope, and side condition, which demand different verdicts when violated).
- **decision**: Namespacing and versioning of every identifier | **recommendation**: CURIE-form prefix:local-id for all vocabulary drawn from external registries, resolved against a first-party committed prefix registry pinning per prefix: source registry identity, release version, license, and the mechanizable oracle required by the transcription-only ruling; align prefixes with Bioregistry (CC0) where defined. Claim, context, and receipt ids are content-addressed digests over canonical serializations using the GA4GH computed-identifier construction (truncated SHA-512, base64url). A pinned-registry release change is a new context version by supersession. | **rationale**: CURIEs are the established compact form (W3C Note 2010; Bioregistry operationalizes 2,768 prefixes today); pinning releases in a committed registry is the same one-build-mode discipline as Nibli's committed corpus; content-addressed ids are what CQ-D2's invalidation walk and the receipt cache key on, and VRS 2.0 proves the construction works registry-free at scale. | **alternatives_rejected**: Bare URLs/IRIs as identifiers (link-rot and no version pin — the MIRIAM/annotation decay documented for SBML). Unversioned prefixes resolved at query time (a moved registry silently changes meaning). Central id-issuance for claims (contradicts deterministic compilation and offline verification).
- **decision**: Domain typing rules that constrain envelope values compile to envelope constraints | **recommendation**: When a domain rule fixes a property of an envelope value (T1's rate-constant unit as a function of reaction order; a regime predicate's variable types; a stoichiometric amount balance), the domain IR emits it as a typed envelope constraint (unit equation, dimension equation, linear relation over quantities) that the envelope checker verifies without domain knowledge. | **rationale**: This is the seam discipline that keeps B stable: the envelope never interprets domain semantics, yet domain semantics still constrain shared values at compile time — the mechanism by which chemistry checks bind biology models (the co-residence value behind the chem+bio ruling) without merging the IRs. | **alternatives_rejected**: Envelope-side domain knowledge (kernel accretion — Shape A by creep). Domain-side private checking of envelope values (two checkers drift; the second-stratifier failure mode Nibli's --strata dump exists to prevent). Unchecked conventions (SBML's advisory path).
- **decision**: Envelope/domain-IR versioning and packaging discipline | **recommendation**: No optional packages: every release compiles all four domain IR schemas in lockstep with one envelope version; capability gaps are declared in the A.7 capability matrix (unsupported disposition), never as schema optionality. The envelope schema version is part of every claim's identity (per A.5.3); domain IRs may evolve between releases but ship atomically. | **rationale**: SBML's optional-package regime produced decade-stalled drafts and voluntary conformance subsets ('supports SBML' meaning anything); MTK's v9/v10/v11 churn shows what per-component breaking versions cost downstreams. Lockstep with matrix-declared capability keeps 'valid input' a single decidable question per release — and is the release discipline the local workspace already runs. | **alternatives_rejected**: Optional schema packages (SBML Arrays/Dynamic Structures stalled as drafts for years; conformance became self-declared subsets). Independent domain-IR release trains (cross-IR imports make claim identity ambiguous). Feature flags at the schema level (reintroduces optionality under another name).

## adopt

SZS-extension two-axis taxonomy (Stage A ruling, fixed) with obligation-declared result subsets. SMT-LIB v2.7 (2026-03-27) set-logic/sorted-declaration discipline as the obligation fragment-declaration pattern and as the emission target for obl:logic. SciMLBase problem-type pattern (v3.22.0: ODEProblem/SDEProblem/NonlinearProblem/OptimizationProblem/LinearProblem/IntegralProblem, solve(prob, alg)) as the obligation-language template. FMI 3.0.2 (2024-11-27) modelDescription typed-variable + capability-flag pattern for backend capability declaration. KiSAO (Artistic-2.0) terms for simulation algorithm identity and typed algorithm parameters. UCUM 2.2 (2024-06-17) grammar for unit expressions over SI Brochure 9th edition (2019, updated) base/derived units; GUM/JCGM 100+101 for measurement uncertainty (Stage A ruling). CURIE prefix:local-id form (W3C WG Note 2010-12-16) with Bioregistry-aligned prefixes (CC0) in a first-party committed prefix registry pinning registry release + oracle. GA4GH VRS 2.0 computed-identifier construction (base64url(sha512(blob)[:24])) for content-addressed claim/context/receipt ids, and its SequenceLocation (sequence reference + interbase coordinates) as the biology coordinate-type shape. Cyc-microtheory explicit fail-closed lifting (Stage A ruling). SageMath's canonical-coercion discipline, hardened: declared morphisms only, typed failure, no heuristic pushout. Strict-vs-sugared two-layer surface with normative desugaring (Strict Content MathML pattern) for the Stage C surface language.

## avoid

One universal IR (Shape A): either prose-bound semantics — OpenMath's encoding-level conformance made it a serialization format, dormant CD repo since 2022-06-28 — or generic-predicate encodings of functions/tensors/graphs, a named Gate 1 fidelity failure; kernel accretion couples all four domains to one version. Fully independent per-domain languages (Shape C): loses compile-time chemistry-on-biology checks (the chem+bio co-residence value), drops cross-domain correlation structure (T2), and creates N² hand bridges — the grant-funded-phrasebook burden that died with OpenMath and consumed Sage. Advisory/optional semantics anywhere: SBML's optional units (105xx warnings) and optional annotations sit upstream of the measured ~50% irreproducibility of 455 published models; Modelica's unit="" default narrates its own 5-meters failure. Heuristic cross-domain coercion (Sage's pushout: 'not all parent pairs yield a common structure') — replace with typed compile errors. Optional schema packages and voluntary conformance subsets (SBML Arrays stalled a decade; SED-ML tools emitting algorithms they didn't run). String/XPath addressing of model entities (SED-ML brittleness). Mandating one universal certificate format across backends (SMT-COMP's proof track refused to define a valid proof and vanished after 2023) — record per-backend certificate kind + checker identity in receipts instead. Overloaded single equality (hidden isclose becoming a truth claim). Envelope creep: without the admission rule, B degenerates into A one convenience type at a time.

## open_questions

- Quantity-kind vocabulary source: ISO/IEC 80000 parts are paywalled and UCUM encodes units, not kinds — QUDT quantity-kind IRIs vs ISO 80000 clause references vs a minimal first-party kind list (each needs a mechanizable oracle under transcription-only); unresolved and blocking the envelope Quantity type's kind field.
- Whether invalid_model migrates to the verdict axis (Stage A registered question, SZS treats ContradictoryAxioms as success) — the obligation result-subset declarations must land after that ruling, not before.
- Molecular-graph exact-identity layer: which InChI layers (standard InChI vs nonstandard, tautomer/stereo handling) define `=` on chemistry species — needs an IUPAC-anchored ruling in B.5 §6.
- Whether the envelope needs a first-class time-instant/interval type (criterion (i) and (iii) arguably pass: physics dynamics and biology assay timepoints) or time stays context-schema content — decide before the context-record schema freezes.
- Representation of the cross-obligation covariance object (dense matrix vs sparse factor structure vs named-correlation graph) and whether it survives lowering through obl:uncertainty-propagation intact — feeds the pre-registered B.7 don't-build trigger.
- SMT-LIB 2.7's exact normative status of set-logic obligation and its proof-output story (Stage A evidence-incomplete carryover; front page fetched today does not restate the mandate — verify against the v2.7 PDF before Stage C emitters are specified).
- Whether the domain-IR import DAG (biology→chemistry→math) reintroduces the release coupling that lockstep versioning is supposed to make tractable — a biology-only fix forcing a full-release cycle is the cost to measure.
- KiSAO coverage of the non-biology obligation classes (optimization, exact linear algebra have no KiSAO terms) — decide whether the first-party method registry mints synthetic method ids under the zzmeta-style pattern or a second external vocabulary (e.g., an optimization-ontology) is adopted.
- Whether any obligation needs a domain object as its direct payload (future substructure-search over molecular graphs would bypass the math-IR lowering rule) — the two-spine rule currently scopes the lowering claim to numeric obligations only; confirm the boundary in B.9.
